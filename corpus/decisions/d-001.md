Context: Ledgerline needs a datastore for timesheets, invoices, and client
records. Studio write volume is small — one billing run a month plus daily
timesheets.

Options considered: Postgres (operational weight, a server to babysit)
versus SQLite (single file, WAL mode, embedded).

Decision: use SQLite in WAL mode as the sole datastore for Ledgerline v1;
Postgres stays out of scope until a second-writer need appears.

Consequences: zero server operations; backups are file copies; the
single-writer ceiling is accepted. Informed by the WAL-mode reading notes
(sqlite-wal-notes).
