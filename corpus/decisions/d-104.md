Context: Harrowgate's digitization covers a century of print; OCR throughput
sets the schedule, and per-page API costs scale with it.

Options considered: a remote OCR API billed per page; a local two-GPU
cluster running overnight batches.

Decision: route Foxglove OCR through the local GPU cluster with a job queue
— no per-page cost, layouts emitted as hOCR for the gallery, informed by the
hOCR notes and the bench results (gpu-cluster-notes).

Consequences: the studio owns the hardware and the queue; throughput is
assumed to hold on modern stock. Confirmed by the March benchmark (s-113).
