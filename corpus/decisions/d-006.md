Context: Greenline's wallboard needs ad-hoc joins across sensor feeds and
Northpost load forecasts.

Options considered: a time-series server for raw telemetry; DuckDB embedded
over Parquet and CSV.

Decision: Beacon Grid lands sensor data in DuckDB and queries it with plain
SQL — the wallboard needs joins more than a retention engine, informed by
duckdb-notes.

Consequences: no database server to operate; ingestion is batch-oriented.
Greenline later flagged access-approval processes, and the project paused
(2026-05-26).
