Context: Harrowgate wants its digitized collections viewable anywhere the
press can host them; a deep-zoom server means one more machine to operate
and a locked layout.

Options considered: a deep-zoom image server; a static-file gallery that
ships to any host.

Decision: Foxglove ships a static-file gallery — full-page spreads, captions
from the Saltmarsh house style, files to any static host — informed by
static-site-gallery-notes.

Consequences: no viewer server to operate; deep zoom is traded for
portability, prototyped in s-122 and shown at the Harrowgate review (m-112).
